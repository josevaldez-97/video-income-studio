# Piloto 01 — ¿Tu celular está lento?
Formato: 9:16; duración objetivo: 30 segundos; audiencia: usuarios de Android.

Guion propuesto para revisión:
1. (0–5 s) ¿Tu celular está lento? Antes de gastar, comprobá tres cosas.
2. (5–10 s) Primero, reinicialo y probá si mejora.
3. (10–15 s) Revisá el almacenamiento. Eliminá archivos que ya no necesites.
4. (15–20 s) Actualizá tus aplicaciones desde las tiendas oficiales.
5. (20–25 s) Probá el rendimiento después de cada cambio, así sabés qué ayudó.
6. (25–30 s) Menos trucos, más soluciones. Seguime para más tecnología práctica.
