# Plantilla Remotion — Piloto 01

Requiere Node.js y npm, en un entorno separado de otros proyectos.

```bash
npm install
npm run start
npm run render
```

Secuencia 9:16, 720x1280, 24 fps, 720 cuadros (30 s). La plantilla no incluye locución, música ni imágenes externas. **No probada con Remotion todavía.**
